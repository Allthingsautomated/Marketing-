# AllThings Automated — Marketing Agency Website

A professional, fully responsive marketing website for **AllThings Automated** — a full-service agency specialising in:

- ⚡ **Electrical Services** — Licensed installs, panel upgrades, EV chargers, 24/7 emergency
- 🏠 **Home Automation** — Smart lighting, climate, AV, energy management
- 🌐 **Network Infrastructure** — Structured cabling, Wi-Fi 6, firewalls, CCTV
- 🤖 **Workflow Automation** — Process automation, CRM integrations, AI-assisted pipelines
- 🔒 **Security Systems** — CCTV, intruder alarms, access control

---

## Project Structure

```
Marketing-/
├── index.html              # Home page
├── css/
│   └── style.css           # Full stylesheet (dark theme, responsive)

│   ├── services.html       # Detailed services page
│   ├── portfolio.html      # Project portfolio with filter
│   ├── about.html          # Team, values, accreditations
│   └── contact.html        # Contact form + FAQ

    ├── img/                # Image assets
    └── icons/              # Icon assets
```

## Features

- **Dark, modern UI** with gradient accents and subtle grid backgrounds
- **Fully responsive** — mobile, tablet, and desktop
- **Animated counters** on the hero stats
- **Scroll-triggered animations** (lightweight, no library dependency)
- **Portfolio filter** — filter projects by category
- **FAQ accordion** on the contact page
- **Contact form** with client-side validation
- **Sticky navigation** with mobile hamburger menu
- **Marquee strip** for service category highlights
- **Zero external JS dependencies** — vanilla JavaScript only

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter + Space Grotesk)

## Getting Started

Open `index.html` in any modern browser. No build step required.
